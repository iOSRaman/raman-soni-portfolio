# Raman Soni — Senior iOS Developer Portfolio

Premium responsive static portfolio for Raman Soni.

## Included
- Apple-inspired black theme with responsive light sections
- Animated iOS-style phone mockups and project previews
- Real profile photo
- Real resume PDF (`resume.pdf`)
- Real Outskill certificate PDF (`generative-ai-engineering-mastermind-certificate.pdf`)
- Certificate thumbnail generated from the supplied certificate PDF (`assets/certificate-preview.jpg`)
- Selected professional experience and App Store projects sourced from the supplied resume
- Netlify Forms contact form
- Central content configuration in `script.js`

## Edit content
Open `script.js` and update the `SITE` object. Replace the GitHub placeholder with the real profile URL.

## Run locally
Use any static server, for example:

```bash
python3 -m http.server 8080
```

Then open `http://localhost:8080`.

## Deploy
Deploy the entire `ios-portfolio` folder to Netlify. Keep `index.html` at the project root. The contact form is configured for Netlify Forms.
